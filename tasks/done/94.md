# Задача 94. Demo profile: любые ручки без доступа к БД

- **Лабораторная:** ЛР2
- **Исполнитель:** Семен
- **Сервис:** `all services`
- **Статус:** done
- **Оценка изменений:** до 1800 строк, generated-код не считается
- **Зависит от:** 74–93

## Цель

Сделать систему полностью проверяемой через Swagger на чистом Docker окружении.

## Что сделать

1. Добавить profile `demo` с детерминированными UUID и связанными fixtures каждого сервиса.
2. Подготовить user, categories, content, report, assessment, quiz, competition, plans, subscription, notification templates и analytics events.
3. Добавить OpenAPI examples с реальными demo ID и порядок stateful сценариев.
4. Добавить безопасный локальный reset script, пересоздающий Compose volumes; никаких production reset endpoints.

## Критерии готовности

- [x] После reset все GET/POST/PUT/DELETE можно выполнить без SQL и psql.
- [x] Примеры не используют несуществующие FK и не требуют Authorization.
- [x] Mock payment, AI и notification scenarios не обращаются во внешнюю сеть.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.

## Проверка

- Unit-тесты для новой логики; integration/Testcontainers для данных и HTTP.
- Запустить проверки изменённых модулей и корневые `./gradlew test openApiValidate build`.
- Проверить запуск изменённых контейнеров и соответствие `docs/lab2-architecture.md`.

## Реализация и проверка

- Service-owned demo Flyway fixtures связаны детерминированными UUID; Event Receiver
  создаёт пять analytics events через собственный ingestion с идемпотентными event IDs.
- Добавлены рабочие request/path examples OpenAPI и `docs/demo-runbook.md` со stateful
  последовательностями, profile prerequisites и таблицей IDs.
- `scripts/reset-demo.ps1` ограничен erudit-demo*, проверяет volume labels и не имеет
  production reset endpoints. Неподходящий project отклоняется до Docker.
- Повторный reset и 50 HTTP-проверок прошли без SQL/psql; фикстура mock receipt
  терминальная, повторная доставка планировщиком не требуется.
