## Цель

Перенести оставшиеся content-сценарии и административные internal операции.

## Что сделать

1. Перенести view/complete/progress, infinite feed, reports, moderation queue и решения.
2. Сохранить feed без total count и paged moderation/report lists с total.
3. На этапе извлечения сохранить локальную генерацию quiz cards; AI Feign добавляется задачей 89.
4. Предоставить internal moderation API для admin; внешние legacy paths сохраняет Gateway.
