# Задача 13. Удаление аккаунта и выход на всех устройствах

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.11, 1.12

## Описание

Реализовать удаление аккаунта и выход на всех устройствах (инвалидация всех refresh-токенов).
Регистрация и отзыв push-токенов выделены в задачу 60.

## Что должно получиться

- `DELETE /api/v1/users/me` — удаление/деактивация аккаунта.
- `POST /api/v1/auth/logout-all` — отзыв всех refresh-токенов пользователя.
- При удалении аккаунта связанные push-токены отзываются через механизм задачи 60.

## Критерии готовности

- [ ] Удаление аккаунта деактивирует доступ.
- [ ] Выход на всех устройствах отзывает все refresh-токены.
- [ ] После удаления аккаунта токены его устройств недоступны для отправки.
