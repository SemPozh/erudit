# Задача 15. CRUD контента (admin) и мягкое удаление

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** done
- **Связанные требования:** REQ 4.12, 1.14

## Описание

Реализовать CRUD контента для админов: создание, обновление, мягкое удаление/архивация.
Контент доступен пользователям только после публикации.

## Что должно получиться

- `POST /api/v1/content`, `PUT /api/v1/content/{id}` и
  `DELETE /api/v1/content/{id}` (admin) с валидацией.
- Мягкое удаление (статус ARCHIVED) без потери истории использования.
- `GET /api/v1/content/{id}` доступен для PUBLISHED пользователям и для любых — админу.

## Критерии готовности

- [x] Админ создаёт/редактирует/архивирует контент.
- [x] Не-админ не может менять контент (403).
- [x] Архив не ломает историю использования.
