# Задача 98. Полный Docker Compose микросервисной системы

- **Лабораторная:** ЛР2
- **Исполнитель:** Илья
- **Сервис:** `platform`
- **Статус:** done
- **Оценка изменений:** до 1800 строк, generated-код не считается
- **Зависит от:** 73, 74–94

## Цель

Собрать все приложения и хранилища в едином воспроизводимом окружении.

## Что сделать

1. Добавить отдельные PostgreSQL databases/users, ClickHouse, все сервисы и volumes.
2. Настроить startup через health/readiness и Config/Eureka discovery.
3. Публиковать наружу только Gateway, Swagger и при необходимости observability.
4. Добавить profiles `demo` и `debug`, resource limits и команды диагностики.

## Критерии готовности

- [x] `docker compose up --build` приводит систему в healthy без ручных действий.
- [x] Перезапуск отдельного сервиса не требует пересборки остальных.
- [x] `docker compose down -v` и demo reset дают повторяемое состояние.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.

## Проверка

- Unit-тесты для новой логики; integration/Testcontainers для данных и HTTP.
- Запустить проверки изменённых модулей и корневые `./gradlew test openApiValidate build`.
- Проверить запуск изменённых контейнеров и соответствие `docs/lab2-architecture.md`.

## Реализация и проверка

- Default Compose включает все 8 бизнес-сервисов, Gateway/Config/Eureka, 7 PostgreSQL
  и ClickHouse; добавлены отсутствовавшие AI default startup/healthcheck.
- Demo/debug overlays, JVM/CPU/PID/memory budgets, локальный ClickHouse schedule pool,
  Gradle BuildKit cache; внутренние порты публикуются только opt-in debug на loopback.
- Fresh media-volume наследует appuser ownership; multipart upload/download проходит
  без ручного chown и без root-процесса приложения.
- `scripts/smoke-platform.ps1`: все 19 healthy на свежих томах normal profile,
  только Gateway снаружи, User restart без rebuild, demo fixtures не просачиваются.
- Полный demo reset и HTTP suite повторяемы; временный normal test project/volumes/
  networks удаляются. Основное окружение не останавливается и не сбрасывается.
