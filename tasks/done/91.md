# Задача 91. Feign contracts и Resilience4j policy

- **Лабораторная:** ЛР2
- **Исполнитель:** Илья
- **Сервис:** `platform/integration`
- **Статус:** done — internal Feign contracts и единая resilience policy добавлены
- **Оценка изменений:** до 1700 строк, generated-код не считается
- **Зависит от:** 67, 68, 69, 72

## Цель

Унифицировать межсервисные HTTP-контракты, timeout и Circuit Breaker.

## Что сделать

1. Добавить internal OpenAPI/DTO для user lookup, moderation, notification enqueue, entitlement, content lookup и analytics event.
2. Настроить OpenFeign discovery, request ID interceptor и единые timeout из Config Server.
3. Создать именованные Circuit Breaker policies и разрешить retry только GET/idempotent operations.
4. Не использовать Feign в реактивном event loop; вызывать через выделенный scheduler либо WebClient там, где требуется реактивность.

## Критерии готовности

- [x] Есть тесты closed/open/half-open и общего fallback executor.
- [x] Internal API не доступен через Gateway.
- [x] Нет shared Entity и ручных дублирующихся DTO между client/server.

## Реализация

- `erudit-integration` содержит только internal value contracts и типизированные Feign clients, без Entity.
- Request ID переносится Feign interceptor и task decorator; timeout/policy приходят из Config Server.
- Retry отключён по умолчанию; реактивные сервисы продолжают изолировать блокирующие клиенты scheduler-ами.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
