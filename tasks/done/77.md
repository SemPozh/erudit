## Цель

Извлечь создание и чтение контента, каталог, форматы и файловое хранилище.

## Что сделать

1. Перенести content, tags, catalog filters/sort и media metadata/files на Spring Data JPA/JDBC repositories.
2. Сохранить лимит page size 50, allowlist sort и `X-Total-Count`.
3. Оставить локальный volume/mock storage; отдельный файловый сервис относится к будущей работе.
4. Создание/изменение/архивирование открыты в ЛР2 без роли ADMIN.

## Критерии готовности

- [x] Все content/media paths работают через Gateway.
- [x] Файл переживает рестарт контейнера.
- [x] Контрактные и интеграционные тесты покрывают CRUD, фильтры, validation и media limits.

## Реализация

- Добавлены OpenAPI-first CRUD контента, каталог, справочник форматов и media API.
- PostgreSQL хранит content/tags/metadata, а файлы — именованный Docker volume.
- Каталог ограничен 50 элементами, использует allowlist сортировки и `X-Total-Count`.
- Все операции открыты без Spring Security и Authorization.
