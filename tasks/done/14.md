# Задача 14. Модель контента

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** done
- **Связанные требования:** REQ 4.1, 4.2, 4.3

## Описание

Создать модель контента: типы (статья, карточка-факт, аудио, видео, комбинированный,
квиз-блок), категории (тематики), форматы, метаданные (теги, длительность, сложность,
автор, статус публикации).

## Что должно получиться

- Сущности `Content`, `Category`, справочник форматов/типов.
- Поля метаданных: теги, время прохождения, автор, уровень сложности, статус.
- Миграции и репозитории.

## Критерии готовности

- [x] Модель покрывает все требуемые форматы и метаданные.
- [x] Категории и статусы описаны.
- [x] Базовые тесты на сохранение/чтение контента.

## Привязка к OpenAPI

Миграции и модель контента; собственный HTTP-маршрут не вводится.
