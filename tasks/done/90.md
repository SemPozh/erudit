# Задача 90. Admin service: фасад и аудит

- **Лабораторная:** ЛР2
- **Исполнитель:** Дестини
- **Сервис:** `erudit-admin`
- **Статус:** done
- **Оценка изменений:** до 1900 строк, generated-код не считается
- **Зависит от:** 74, 78, 84, 86, 91

## Цель

Извлечь административный API как оркестратор без доступа к чужим базам.

## Что сделать

1. Перенести admin audit в собственный PostgreSQL через Spring Data JPA/JDBC.
2. Реализовать users/block, moderation/reports, notification send-many и payment views через Feign.
3. Сохранять audit результата и request ID локально.
4. Не проверять роль ADMIN в ЛР2; описание Swagger явно указывает учебный режим.

## Критерии готовности

- [x] В admin module нет repositories/Entity чужих доменов.
- [x] Partial failure даёт структурированную ошибку и audit status.
- [x] Интеграционные тесты используют stub services и собственный PostgreSQL Testcontainer.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.

## Проверка

- Unit-тесты для новой логики; integration/Testcontainers для данных и HTTP.
- Запустить проверки изменённых модулей и корневые `./gradlew test openApiValidate build`.
- Проверить запуск изменённых контейнеров и соответствие `docs/lab2-architecture.md`.

## Результат проверки (2026-11-04)

- Admin имеет собственные PostgreSQL/admin_audit и Spring Data JDBC. Импортов
  Entity/repositories других доменов в admin module нет.
- User search/block, Content moderation/reports, локальная notification queue
  и read-only Payment views вызываются типизированными Feign clients.
- Actor и X-Request-ID передаются в запросы и аудит. RUNNING сохраняется до
  network call; SUCCESS/FAILED/PARTIAL/UNKNOWN — отдельно от удалённой операции.
  Частичный batch возвращает структурированный 503 с подтверждённым sent count.
- Автоматические повторы записывающих Feign/LoadBalancer вызовов выключены.
  Нет JWT, проверки ролей и настоящих провайдеров уведомлений.
- User restriction хранится только в user БД в независимой R-миграции, не
  занимающей V2 задачи 75. Block идемпотентен, internal lookup отражает active=false.
- Gateway теперь направляет все /api/v1/admin/** в Admin facade. Internal API
  остаются закрытыми извне. Общий OpenAPI и временный legacy adapter обновлены.
- `gradlew test openApiValidate build`: успешно, 285 тестов, 0 падений/пропусков;
  покрытие строк admin 100%, user 96%, content 96.1% без generated-кода.
- Интеграционные тесты admin используют JDK HTTP stubs и собственный PostgreSQL:
  success, partial failure, timeout, malformed response, 404 без retry,
  actor/request ID и audit filters. User API проверен своим PostgreSQL тестом.
- Compose Admin/User/Content/Notificator/Gateway healthy; `scripts/smoke-admin.ps1`
  прошёл реальные Feign-вызовы, mock batch и аудит. Созданный fixture-пользователь
  удалён, fixture-контент архивирован.
- Документация: `docs/admin-facade.md`. База отдельного PR — актуальный main
  после слияния зависимостей 86/87/78. Задачи 75/80/85 не реализовывались.
