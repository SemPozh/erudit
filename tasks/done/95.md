# Задача 95. Интеграционные и contract tests микросервисов

- **Лабораторная:** ЛР2
- **Исполнитель:** Дестини
- **Сервис:** `quality`
- **Статус:** done
- **Оценка изменений:** до 1900 строк, generated-код не считается
- **Зависит от:** 74–94

## Цель

Закрыть тестами границы сервисов и регрессии декомпозиции.

## Что сделать

1. Добавить PostgreSQL/R2DBC/ClickHouse Testcontainers по владельцам.
2. Добавить HTTP contract tests по OpenAPI и Feign stub tests.
3. Проверить pagination ≤50, enums-as-strings, validation, errors, transactions и fallbacks.
4. Сохранить общий порог JaCoCo 70% без generated code.

## Критерии готовности

- [x] Каждый сервис запускает тесты независимо.
- [x] Тесты не зависят от порядка и локальных БД разработчика.
- [x] CI публикует отчёты по модулям и падает при нарушении coverage/contract.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.

## Проверка

- Unit-тесты для новой логики; integration/Testcontainers для данных и HTTP.
- Запустить проверки изменённых модулей и корневые `./gradlew test openApiValidate build`.
- Проверить запуск изменённых контейнеров и соответствие `docs/lab2-architecture.md`.

## Реализация и проверка

- PostgreSQL owner test применяет также demo migrations; R2DBC/ClickHouse тест
  проверяет повторный demo startup без дубликатов. Сервисные HTTP/Feign tests сохранены.
- Строгий YAML/OpenAPI guard проверяет uniqueness и валидность examples/fixture IDs.
- `scripts/smoke-demo-contracts.ps1`: 50 проверок response schemas, nullable/enum/types,
  pagination/sort errors, CRUD, stateful conflicts, multipart bytes и event idempotency.
- Исправлены реальные nullable/MIME несоответствия контрактов и fallback при null/
  blank AI полях Content/Quiz. Добавлены regression tests, локальные данные сохраняются.
- CI: 14 независимых module test/check jobs, стабильный aggregate test gate, JUnit/
  HTML/JaCoCo artifacts, demo HTTP suite. Порог 70% без generated code сохранён.
- Полные `test openApiValidate build`: 310 тестов без ошибок/пропусков.
