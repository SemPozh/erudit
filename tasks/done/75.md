# Задача 75. User service: друзья и push-токены

- **Лабораторная:** ЛР2
- **Исполнитель:** Дестини
- **Сервис:** `erudit-user`
- **Статус:** done — друзья и локальный реестр устройств перенесены в user service
- **Оценка изменений:** до 1700 строк, generated-код не считается
- **Зависит от:** 74

## Цель

Перенести социальные связи и реестр устройств в user service.

## Что сделать

1. Перенести заявки, принятие/отклонение, список и удаление друзей.
2. Перенести регистрацию и отзыв push-токенов как данные устройств.
3. Не отправлять push и не вызывать внешние провайдеры.
4. Добавить internal API чтения минимального профиля/устройств для notificator.

## Критерии готовности

- [x] Повторы операций идемпотентны и чужие записи не изменяются.
- [x] Internal DTO не раскрывают password/email без необходимости.
- [x] Тесты покрывают пагинацию, связи и отсутствие реальной доставки.

## Реализация

- Добавлены friend requests, friendships и user devices в собственной PostgreSQL.
- Повторные заявки и push-токены возвращают существующую запись; решения ограничены адресатом.
- Internal profile содержит только UUID, display name, active и device IDs; отправки push нет.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
