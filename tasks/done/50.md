# Задача 50. Лимиты, тихие часы, дедупликация, фолбэк каналов

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-notificator
- **Статус:** done
- **Связанные требования:** REQ 8.11, 8.12, NFR 14

## Описание

Ограничить число уведомлений в сутки, не отправлять в тихие часы, предотвращать дубликаты
и выполнять фолбэк Push → Email при недоставке.

## Что должно получиться

- Суточный лимит уведомлений на пользователя (конфигурируемо).
- Проверка тихих часов перед отправкой.
- Дедупликация повторных уведомлений одного типа.
- Фолбэк Push → Email при отсутствии доставки/токена.

## Критерии готовности

- [x] Лимит в сутки соблюдается.
- [x] Тихие часы блокируют отправку.
- [x] Дубликаты и фолбэк каналов обрабатываются.

## Привязка к OpenAPI

Триггеры достижений используют доставку задачи 48; нового маршрута нет.

Предшествующие задачи: №46, №48.
