# Задача 60. Push-токены устройств пользователя

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** done
- **Связанные требования:** REQ 1.13, 8.8
- **Зависит от:** 6 (пользователь), 9 (аутентификация)

## Зачем

У одного пользователя может быть несколько устройств. Нотификатору нужен актуальный
набор токенов, а пользователь должен иметь возможность отозвать отдельный токен.
Эта часть выделена из задачи 13, чтобы удаление аккаунта не блокировало доставку Push.

## Контракт

- `POST /api/v1/users/me/push-tokens` — `PushTokenRequest {token, platform}`; успех `204`.
- `DELETE /api/v1/users/me/push-tokens/{id}` — отзыв одного токена; успех `204`.
- Оба маршрута требуют Bearer-токен. Идентификатор пользователя берётся из него, а не из тела.

## Реализация и готовность

- [x] Таблица и репозиторий связывают токен, платформу и пользователя;
      повторная регистрация того же токена безопасна.
- [x] Удаление токена не затрагивает другие устройства; чужой токен недоступен.
- [x] Нотификатор из задачи 48 читает только активные токены.
- [x] Тесты покрывают регистрацию, повтор, отзыв и попытку отозвать чужой токен.
