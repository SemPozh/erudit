# Задача 9. JWT-фильтр, защита ресурсов, роли

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** done
- **Связанные требования:** REQ 1.14, 1.15

## Описание

Проверять JWT в servlet-фильтре без Spring Security. Публичные маршруты не
требуют principal; защищённые контроллеры проверяют principal и роли USER/ADMIN.

## Что должно получиться

- JWT-фильтр, аутентифицирующий запросы по access-токену.
- Матрица прав: публичные (регистрация, вход, каталог, категории) vs защищённые
  (профиль, прогресс, квизы, друзья, подписка, нотификации, аналитика).
- Роли USER и ADMIN с ограничением админ-эндпоинтов.

## Критерии готовности

- [x] Защищённые эндпоинты требуют токен (401 без него).
- [x] Админ-эндпоинты доступны только роли ADMIN (403 иначе).
- [x] Публичные эндпоинты доступны без токена.

## Привязка к OpenAPI

Проверка Bearer-токена и ролей для защищённых маршрутов; собственного HTTP-маршрута нет.
