# Задача 89. Интеграция Content и Quiz с AI через Feign

- **Лабораторная:** ЛР2
- **Исполнитель:** Илья
- **Сервис:** `content/quiz/ai`
- **Статус:** done — Content и Quiz используют AI Feign с локальным fallback
- **Оценка изменений:** до 1300 строк, generated-код не считается
- **Зависит от:** 77, 80, 88, 91

## Цель

Подключить AI Platform без превращения её в обязательную точку отказа.

## Что сделать

1. Создать типизированные Feign clients из internal contract.
2. Настроить Resilience4j timeout/Circuit Breaker и метрики.
3. Content fallback создаёт локальные cards, Quiz fallback — локальные questions.
4. Идемпотентно сохранять результат только в базе вызывающего домена.

## Критерии готовности

- [x] Тесты проверяют normal, timeout/open circuit fallback и malformed response.
- [x] Остановка AI не ломает создание контента/квиза.
- [x] Внешние `/api/v1` контракты не меняются.

## Реализация

- Общий typed `AiClient` использует internal AI contract и именованный Circuit Breaker `ai`.
- Content сохраняет AI card либо локальные cards; Quiz принимает валидный AI question либо исходные данные.
- Результаты сохраняются только локальными repositories вызывающих сервисов.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
