# Задача 19. Персональная лента рекомендаций

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.6

## Описание

Сформировать персональную ленту рекомендаций контента на основе предпочтений пользователя
(любимые тематики из профиля) и поведенческих сигналов из аналитики.

## Что должно получиться

- `GET /api/v1/content/feed` — ранжированный список контента для пользователя.
- Учёт любимых тематик и истории взаимодействия (сигналы аналитики).
- Фолбэк на популярный/новый контент при нехватке данных.

## Критерии готовности

- [ ] Лента учитывает тематики пользователя.
- [ ] При отсутствии данных выдаётся разумный фолбэк.
- [ ] Покрыто тестами.
