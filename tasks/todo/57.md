# Задача 57. Админ-API: управление пользователями, массовые уведомления

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-admin
- **Статус:** todo
- **Связанные требования:** REQ 1.14, 8.4, NFR 8

## Описание

Реализовать админ-возможности: просмотр/блокировка пользователей, отправка массовых
уведомлений, доступ к модерации контента (переиспользование задачи 20).

## Что должно получиться

- `GET /api/v1/admin/users`, `POST /api/v1/admin/users/{id}/block`.
- `POST /api/v1/admin/notifications/send-many` — массовая отправка.
- Доступ только для роли ADMIN.
- Интеграция с модерацией контента.

## Критерии готовности

- [ ] Админ управляет пользователями (блокировка).
- [ ] Массовые уведомления отправляются.
- [ ] Доступ ограничен ролью ADMIN.
