# Задача 6. Сущность User и регистрация по email/паролю

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.1

## Описание

Создать сущность пользователя и эндпоинт регистрации по email и паролю с безопасным
хешированием пароля. Подготовить почву для остальных функций домена пользователя.

## Что должно получиться

- Сущность `User` (id, email, passwordHash, имя, аватар, дата регистрации, статус) и миграция.
- `POST /api/v1/auth/register`: создание пользователя, хеширование пароля (BCrypt), проверка уникальности email.
- Репозиторий и сервисный слой.

## Критерии готовности

- [ ] Регистрация создаёт пользователя с захэшированным паролем.
- [ ] Дубликат email отклоняется (409).
- [ ] Ключевые сценарии покрыты тестами.
