# Задача 47. Шаблоны уведомлений и админ-API

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-notificator
- **Статус:** todo
- **Связанные требования:** REQ 8.5

## Описание

Создать шаблоны уведомлений по типам и каналам (Push/Email) с параметризацией, и админ-API
управления ими.

## Что должно получиться

- Сущность шаблона (тип, канал, заголовок, тело, параметры).
- `GET/POST /api/v1/notifications/templates` и
  `PUT /api/v1/notifications/templates/{id}` (admin).
- Подстановка параметров в шаблон.

## Критерии готовности

- [ ] Шаблоны по типам и каналам хранятся.
- [ ] Админ управляет шаблонами.
- [ ] Параметры подставляются.

## Привязка к OpenAPI

Источник истины: `src/main/resources/static/openapi.yaml` (`x-task-id: 47`). Поля и коды ошибок берутся из соответствующих схем контракта.

| Метод | Путь | Тело запроса | Успешный ответ | Доступ |
| --- | --- | --- | --- | --- |
| `GET` | `/api/v1/notifications/templates` | `—` | `200 NotificationTemplateListResponse` | Bearer + ADMIN |
| `POST` | `/api/v1/notifications/templates` | `NotificationTemplate` | `201 NotificationTemplateResponse` | Bearer + ADMIN |
| `PUT` | `/api/v1/notifications/templates/{id}` | `NotificationTemplate` | `200 NotificationTemplateResponse` | Bearer + ADMIN |
