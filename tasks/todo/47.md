# Задача 47. Шаблоны уведомлений и админ-API

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-notificator
- **Статус:** todo
- **Связанные требования:** REQ 8.5

## Описание

Создать шаблоны уведомлений по типам и каналам (Push/Email) с параметризацией, и админ-API
управления ими.

## Что должно получиться

- Сущность шаблона (тип, канал, заголовок, тело, параметры).
- `GET/POST/PUT /api/v1/notifications/templates` (admin).
- Подстановка параметров в шаблон.

## Критерии готовности

- [ ] Шаблоны по типам и каналам хранятся.
- [ ] Админ управляет шаблонами.
- [ ] Параметры подставляются.
