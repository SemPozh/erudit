# Задача 8. Авторизация JWT (access/refresh), вход, выход

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.2, 1.3, 1.12

## Описание

Реализовать вход по email/паролю и механику токенов доступа и обновления (access/refresh),
включая выход.

## Что должно получиться

- `POST /api/v1/auth/login` — выдаёт access и refresh токены.
- `POST /api/v1/auth/refresh` — обновление access по refresh.
- `POST /api/v1/auth/logout` — инвалидация/отзыв refresh-токена.
- Хранение/валидация refresh-токенов.

## Критерии готовности

- [ ] Вход выдаёт токены; неверные креды отклоняются (401).
- [ ] Refresh обновляет access; отозванный refresh не принимается.
- [ ] Выход отзывает refresh-токен.
