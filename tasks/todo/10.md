# Задача 10. Восстановление пароля

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.4

## Описание

Реализовать восстановление пароля по email: запрос сброса, отправка ссылки/кода, смена
пароля.

## Что должно получиться

- `POST /api/v1/auth/password/reset-request` — генерация одноразового токена и письмо.
- `POST /api/v1/auth/password/reset` — смена пароля по токену.
- Одноразовость и срок действия токена.

## Критерии готовности

- [ ] Запрос сброса генерирует токен и письмо.
- [ ] Смена пароля по токену работает, старый пароль недействителен.
- [ ] Повторное использование токена отклоняется.

Источник истины: `src/main/resources/static/openapi.yaml` (`x-task-id: 10`). Поля и коды ошибок берутся из соответствующих схем контракта.
