## Цель

Поднять Eureka и подготовить единые правила регистрации всех приложений.

## Что сделать

1. Создать Eureka Server без регистрации самого себя.
2. Настроить service ID, instance ID, health URL и graceful deregistration через Config Server.
3. Добавить smoke-проверку реестра без зависимости от HTML dashboard.

## Критерии готовности

- [ ] Gateway и тестовый сервис появляются в registry и исчезают после остановки.
- [ ] Регистрация не требует ручного URL сервиса.
- [ ] Eureka имеет Docker healthcheck.
