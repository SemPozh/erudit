# Задача 22. Прогресс по контенту и эмиссия событий

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.13, 9.3

## Описание

Отслеживать прогресс пользователя по каждому контенту (просмотр, завершение) и публиковать
события аналитики (content_viewed, content_started, content_completed) через внутренний
публикатор.

## Что должно получиться

- Сущность прогресса по контенту (userId, contentId, статус, даты).
- Эндпоинты отметки просмотра/завершения и чтения прогресса.
- Публикация событий аналитики при действиях.

## Критерии готовности

- [ ] Прогресс корректно сохраняется и читается.
- [ ] События публикуются при просмотре/завершении.
- [ ] Покрыто тестами.
