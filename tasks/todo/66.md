# Задача 66. Публичный каталог тарифов

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-payment
- **Статус:** todo
- **Связанные требования:** REQ 7.1, 7.2
- **Зависит от:** 40 (модель тарифов)

## Зачем

Перед `POST /api/v1/subscriptions` клиенту нужен список доступных тарифов.
Модель тарифа есть в задаче 40, но отдельного API для выбора не было.

## Контракт

- `GET /api/v1/subscriptions/plans` — публичный маршрут; ответ
  `SubscriptionPlanListResponse` с `code`, `name`, `price` (десятичная строка),
  `currency`, `period`.

## Готовность

- [ ] Возвращаются только доступные для оформления тарифы в стабильном порядке.
- [ ] Цена и валюта совпадают с тем, что использует создание подписки; архивный тариф
      недоступен для нового оформления.
- [ ] Тесты покрывают пустой каталог, активные и архивные тарифы.
