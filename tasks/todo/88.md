# Задача 88. AI Platform: API и локальный mock provider

- **Лабораторная:** ЛР2
- **Исполнитель:** Илья
- **Сервис:** `erudit-ai-platform`
- **Статус:** todo
- **Оценка изменений:** до 1500 строк, generated-код не считается
- **Зависит от:** 67, 68, 69, 72

## Цель

Создать отдельную платформу AI с детерминированной локальной реализацией.

## Что сделать

1. Определить internal OpenAPI для quiz generation и content cards.
2. Реализовать mock provider с детерминированным результатом и validation ответа.
3. Добавить timeout, rate limit и structured error; внешний AI URL/ключ не требуются.
4. Не сохранять доменные Entity content/quiz.

## Критерии готовности

- [ ] Mock одинаково отвечает на одинаковый seed.
- [ ] Контрактные тесты проверяют успешный и malformed generation result.
- [ ] Сервис регистрируется в Eureka и получает config из Config Server.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.

## Проверка

- Unit-тесты для новой логики; integration/Testcontainers для данных и HTTP.
- Запустить проверки изменённых модулей и корневые `./gradlew test openApiValidate build`.
- Проверить запуск изменённых контейнеров и соответствие `docs/lab2-architecture.md`.
