# Задача 37. Поиск пользователей

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 6.3

## Описание

Реализовать поиск других пользователей по имени/email с учётом настроек приватности.

## Что должно получиться

- `GET /api/v1/users/search?query=` — поиск по имени/email.
- Пагинация и фильтрация по приватности (скрытые профили исключаются).

## Критерии готовности

- [ ] Поиск по имени и email работает.
- [ ] Пользователи со скрытым профилем не попадают в поиск.
- [ ] Покрыто тестами.
