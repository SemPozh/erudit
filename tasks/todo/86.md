## Цель

Извлечь тарифы, подписки и проверку premium в собственную БД.

## Что сделать

1. Перенести plans, subscriptions, payments, Spring Data JPA/JDBC repositories и Flyway migrations.
2. Сохранить public plans, create/current/cancel/payment history paths.
3. Добавить internal entitlement API для content и demo plans с постоянными code.
4. Проверять существование пользователя через Feign без общей БД.

## Критерии готовности

- [ ] Тарифы и подписка полностью тестируются из Swagger.
- [ ] Content получает premium только через internal API.
- [ ] Транзакционные тесты покрывают создание, отмену, expiration и недоступный user service.
