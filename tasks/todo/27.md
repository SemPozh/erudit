# Задача 27. Подбор образовательной программы

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-ai-platform
- **Статус:** todo
- **Связанные требования:** REQ 3.1, 3.2, 3.4, 3.6

## Описание

Формировать персональную образовательную программу: структура модулей/тем → уроков
(контент + проверочный квиз), с учётом уровня по тематикам и понятным прогрессом.

## Что должно получиться

- Сущности программы: модуль, тема, урок; связь урока с контентом и квизом.
- Алгоритм построения программы по результатам входного теста и уровню по тематикам.
- Прогресс по модулям, темам и всей программе.

## Критерии готовности

- [ ] Программа строится персонально по уровню пользователя.
- [ ] Структура модулей/тем/уроков корректна.
- [ ] Прогресс программы отражается.
