# Задача 46. Предпочтения нотификаций и их API

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-notificator
- **Статус:** todo
- **Связанные требования:** REQ 8.9, 8.10

## Описание

Реализовать предпочтения нотификаций пользователя: какие типы получать, канал (Push/Email),
время, тихие часы. Изменения вступают в силу сразу.

## Что должно получиться

- Сущность предпочтений нотификаций (типы, каналы, время, тихие часы).
- `GET/PUT /api/v1/notifications/preferences`.
- Учёт предпочтений при планировании/отправке (доступно другим частям модуля).

## Критерии готовности

- [ ] Предпочтения читаются и обновляются.
- [ ] Изменения сразу учитываются.
- [ ] Покрыто тестами.
