# Задача 13. Удаление аккаунта, выход на всех устройствах, push-токен

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.11, 1.12, 1.13

## Описание

Реализовать удаление аккаунта, выход на всех устройствах (инвалидация всех refresh-токенов)
и хранение push-токена устройства для нотификаций.

## Что должно получиться

- `DELETE /api/v1/users/me` — удаление/деактивация аккаунта.
- `POST /api/v1/auth/logout-all` — отзыв всех refresh-токенов пользователя.
- Сущность push-токенов устройства (пользователь + токен) и API их добавления/удаления.

## Критерии готовности

- [ ] Удаление аккаунта деактивирует доступ.
- [ ] Выход на всех устройствах отзывает все refresh-токены.
- [ ] Push-токен сохраняется и удаляется по необходимости.
