# Задача 16. Медиа: загрузка, хранение, отдача

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.1

## Описание

Реализовать загрузку и хранение медиа (изображения, аудио, видео) для контента и аватаров,
а также отдачу файлов. На старте — локальное хранилище.

## Что должно получиться

- `POST /api/v1/media` — загрузка файла (admin/аватар), валидация типа и размера.
- Хранение файлов и метаданных (ключ, тип, размер).
- Отдача файлов по URL.
- Абстракция хранилища для перехода на S3 позже.

## Критерии готовности

- [ ] Файлы загружаются с валидацией типов/размера.
- [ ] Файлы отдаются по URL.
- [ ] Абстракция позволяет сменить хранилище.
