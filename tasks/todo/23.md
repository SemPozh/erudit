# Задача 23. Входное тестирование

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-ai-platform
- **Статус:** todo
- **Связанные требования:** REQ 2.1, 2.2

## Описание

Реализовать входное тестирование при первом входе: структура теста, вопросы по тематикам,
прохождение и сохранение результата.

## Что должно получиться

- Сущности входного теста, вопросов и вариантов ответа.
- `POST /api/v1/assessment/start` и `/submit` — старт и отправка ответов.
- Сохранение результата прохождения в профиле.

## Критерии готовности

- [ ] Тест стартует и принимает ответы.
- [ ] Вопросы покрывают все тематики.
- [ ] Результат сохраняется для дальнейшей оценки.
