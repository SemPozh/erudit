# Задача 21. Freemium-гейтинг

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.7, 4.8, 4.9

## Описание

Реализовать ограничение доступа к премиум-контенту: пометка контента как премиум, проверка
статуса подписки при доступе, сохранение прогресса при потере подписки.

## Что должно получиться

- Поле `isPremium` у контента.
- Проверка статуса подписки пользователя при выдаче премиум-контента.
- При `GET` премиум-объекты либо исключаются, либо отдаются с `premiumLocked: true` без тела/медиа.
- Потеря подписки не удаляет прогресс по контенту.

## Критерии готовности

- [ ] Без подписки премиум-контент недоступен (locked).
- [ ] С активной подпиской контент доступен.
- [ ] Потеря подписки сохраняет прогресс.

## Привязка к OpenAPI

Правила доступа применяются к чтению контента из задачи 15; отдельного HTTP-маршрута нет.

## Зависимости и проверка

Предшествующие задачи: №40, №43, №15.

Проверить положительный сценарий, ошибки валидации и доступа, а также сохранение/чтение данных там, где это применимо. Для HTTP-маршрутов сверить фактические тела и статусы с OpenAPI и выполнить `./gradlew test openApiValidate build`.
