- **Лабораторная:** ЛР2
- **Исполнитель:** Семен
- **Сервис:** `erudit-notificator`
- **Статус:** todo
- **Оценка изменений:** до 1300 строк, generated-код не считается
- **Зависит от:** 84, 91

## Цель

Перенести планирование уведомлений, жёстко исключив реальную отправку.

## Что сделать

1. Реализовать `MockNotificationSender`, записывающий attempt/status/payload preview в БД.
2. Запретить зависимости Firebase, SMTP, SMS SDK и реальные credentials.
3. Перенести quiet hours, daily limit, retry policy и scheduled triggers.
4. Отправлять best-effort analytics event через Feign/Circuit Breaker.

## Критерии готовности

- [ ] Compose использует только mock sender во всех профилях ЛР2.
- [ ] Тест подтверждает отсутствие сетевого вызова и корректные лимиты/quiet hours.
- [ ] Swagger позволяет посмотреть созданные inbox записи и статусы mock delivery.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
