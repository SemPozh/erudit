## Цель

Перенести интеграционные платёжные сценарии без реального шлюза.

## Что сделать

1. Оставить mock mobile receipt verifier и mock webhook provider.
2. Документировать тестовую подпись/receipt в Swagger examples и Config Server.
3. Сохранить idempotency provider event и порядок renewal/cancel/expire.
4. Не добавлять SDK, ключи или сетевые вызовы реального платёжного шлюза.

## Критерии готовности

- [ ] Webhook и receipt можно вызвать из Swagger на demo profile.
