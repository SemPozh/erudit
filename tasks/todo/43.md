## Описание

Предоставить внутренний сервис проверки статуса подписки пользователя и использовать его
для Freemium-гейтинга контента (задача 21).

## Что должно получиться

- Внутренний интерфейс `isPremiumActive(userId)` / статус подписки.
- `GET /api/v1/subscriptions/me` — статус подписки пользователя.
- Интеграция проверки с доменом контента.

## Критерии готовности

- [ ] Проверка статуса корректна (активна/истекла).
