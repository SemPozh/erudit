# Задача 109. Clean Architecture: user, quiz и admin

- **Лабораторная:** ЛР4
- **Исполнитель:** Дестини
- **Сервис:** `erudit-user / erudit-quiz / erudit-admin`
- **Статус:** todo
- **Оценка изменений:** 1200–2000 строк
- **Зависит от:** 100, 102

## Цель

Перестроить три сервиса на Clean Architecture без изменения их публичного поведения.

## Что сделать

1. Разделить `domain`, `application` (use cases/ports), `adapter.in.web`,
   `adapter.in.kafka`, `adapter.out.persistence/http/kafka`, `config`.
2. Domain и application не должны зависеть от Spring, JDBC, Feign, OpenAPI classes.
3. Generated controllers DTO преобразовывать в application commands/results в web adapter.
4. Репозитории, Feign и event publisher реализовать как output adapters.
5. Устранить service locator, controller→repository и cross-service model imports.
6. Добавить ArchUnit rules и use-case unit tests без Spring context.

## Критерии готовности

- [ ] Dependency direction направлена внутрь и проверяется автоматически.
- [ ] Бизнес-правила тестируются без БД/HTTP/Kafka.
- [ ] Integration adapters имеют отдельные contract tests.
- [ ] OpenAPI и статусы остаются совместимыми.
- [ ] Каждый модуль сохраняет покрытие не ниже 80%.

## API и проверка

Новых маршрутов нет. Прогнать module tests, ArchUnit, OpenAPI diff и существующие
Gateway E2E сценарии пользователей, quiz и admin.
