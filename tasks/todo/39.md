# Задача 39. Триггер «друг обогнал в рейтинге»

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 6.8, 8.6

## Описание

Определять момент, когда друг обогнал пользователя в рейтинге, и инициировать нотификацию
(см. модуль нотификаций). Задача — логика детекции, не сама отправка.

## Что должно получиться

- Детекция изменения позиций друзей в рейтинге.
- Создание события/записи для сервиса нотификаций (тип SOCIAL).
- Публикация события аналитики.

## Критерии готовности

- [ ] Факт «друг обогнал» детектируется.
- [ ] Создаётся уведомление типа SOCIAL.
- [ ] Покрыто тестами.

## Привязка к OpenAPI

Доступ друзей к рейтингу обеспечивается маршрутом GET /api/v1/rating/friends из задачи 36.

## Зависимости и проверка

Предшествующие задачи: №36, №38, №49.

Проверить положительный сценарий, ошибки валидации и доступа, а также сохранение/чтение данных там, где это применимо. Для HTTP-маршрутов сверить фактические тела и статусы с OpenAPI и выполнить `./gradlew test openApiValidate build`.
