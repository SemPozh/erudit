# Задача 49. Планировщик триггеров нотификаций

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-notificator
- **Статус:** todo
- **Связанные требования:** REQ 8.1, 8.2, 8.3, 8.4, 8.6, 8.7

## Описание

Реализовать периодические триггеры нотификаций: неактивность (N дней с эскалацией),
ежедневный квиз (по времени пользователя), новый контент в любимых категориях, достижения,
социальные события, статус подписки.

## Что должно получиться

- Планировщик (Scheduler/Quartz) с набором заданий по каждому триггеру.
- Определение целевых пользователей (неактивные, время квиза, новый контент и т.д.).
- Эскалация неактивности (3 дня — мягкое, 7+ — мотивирующее).
- Создание уведомлений через сервис отправки.

## Критерии готовности

- [ ] Все триггеры создают уведомления по расписанию.
- [ ] Эскалация неактивности работает.
- [ ] Время ежедневного квиза учитывает предпочтения.
