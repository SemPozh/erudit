# Задача 29. Следующий шаг, ежедневные цели и streak

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-ai-platform
- **Статус:** todo
- **Связанные требования:** REQ 3.7, 3.8, 3.9

## Описание

Реализовать предложение следующего шага/урока по текущему прогрессу, ежедневные цели
(минуты/уроки) и цепочку ежедневных занятий (streak).

## Что должно получиться

- Эндпоинт «следующий шаг» по прогрессу.
- Учёт ежедневной цели из настроек профиля.
- Расчёт и хранение streak (непрерывные дни занятий).

## Критерии готовности

- [ ] Следующий шаг корректен по прогрессу.
- [ ] Streak корректно растёт/сбрасывается.
- [ ] Ежедневная цель учитывается.
