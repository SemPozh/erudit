# Задача 20. Модерация контента и жалобы

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.10, 4.11

## Описание

Реализовать модерацию нового контента перед публикацией и приём жалоб пользователей.

Каркас `POST /api/v1/content/{id}/report` и хранение жалоб уже добавлены.
Валидация тела — задача 59. Рассмотрение жалоб администратором — задача 61.
Здесь остаются очередь модерации контента, approve/reject и защита этих действий.

## Что должно получиться

- Статусы модерации (DRAFT → PENDING_MODERATION → PUBLISHED / REJECTED).
- Очередь на проверку и approve/reject (admin).
- `POST /api/v1/content/{id}/report` — жалоба пользователя.
- Снятие контента с публикации решением администратора; сценарий по жалобе — задача 61.

## Критерии готовности

- [ ] Новый контент не публикуется до одобрения.
- [ ] Approve/reject меняют статус.
- [ ] Жалоба на существующий контент создаётся; её решение покрывается задачей 61.
