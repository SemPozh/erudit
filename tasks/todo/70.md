## Цель

Создать единую внешнюю точку входа на Spring Cloud Gateway с маршрутами по service ID.

## Что сделать

1. Перенести внешние `/api/v1/**` маршруты без изменения путей.
2. Добавить CORS, ограничения тела, request/response logging и генерацию/проброс `X-Request-ID`.
3. Пробрасывать необязательный `X-User-Id`; не добавлять JWT, SecurityFilterChain и проверки ролей.
4. Закрыть наружную маршрутизацию `/internal/v1/**`, Eureka и Config Server.

## Критерии готовности

- [x] Маршруты разрешаются через Eureka, а не фиксированные host:port.
- [x] Запрос без Authorization достигает целевого сервиса.
- [x] Неизвестный маршрут даёт структурированный 404, недоступный сервис — структурированный 503.
