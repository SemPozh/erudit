# Задача 94. Demo profile: любые ручки без доступа к БД

- **Лабораторная:** ЛР2
- **Исполнитель:** Семен
- **Сервис:** `all services`
- **Статус:** todo
- **Оценка изменений:** до 1800 строк, generated-код не считается
- **Зависит от:** 74–93

## Цель

Сделать систему полностью проверяемой через Swagger на чистом Docker окружении.

## Что сделать

1. Добавить profile `demo` с детерминированными UUID и связанными fixtures каждого сервиса.
2. Подготовить user, categories, content, report, assessment, quiz, competition, plans, subscription, notification templates и analytics events.
3. Добавить OpenAPI examples с реальными demo ID и порядок stateful сценариев.
4. Добавить безопасный локальный reset script, пересоздающий Compose volumes; никаких production reset endpoints.

## Критерии готовности

- [ ] После reset все GET/POST/PUT/DELETE можно выполнить без SQL и psql.
- [ ] Примеры не используют несуществующие FK и не требуют Authorization.
- [ ] Mock payment, AI и notification scenarios не обращаются во внешнюю сеть.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
