# Задача 18. Каталог контента: фильтры, поиск, пагинация, сортировка

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.5

## Описание

Реализовать каталог контента с фильтрами (категория, формат, сложность, премиум), поиском
по названию/описанию, пагинацией и сортировкой.

## Что должно получиться

- `GET /api/v1/content` — пагинированный список с фильтрами.
- `GET /api/v1/content/categories`, `/formats` — справочники.
- Корректное применение всех фильтров одновременно.

## Критерии готовности

- [ ] Все фильтры и поиск работают, в т.ч. вместе.
- [ ] Пагинация корректна.
- [ ] Покрыто тестами.
