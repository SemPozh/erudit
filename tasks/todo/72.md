- **Лабораторная:** ЛР2
- **Исполнитель:** Илья
- **Сервис:** `platform`
- **Статус:** in progress — реализация и локальные проверки готовы, ожидаются CI и ревью
- **Оценка изменений:** до 1500 строк, generated-код не считается
- **Зависит от:** 67

## Цель

Вынести только технические соглашения, одинаковые для всех сервисов.

## Что сделать

1. Добавить общий формат ошибки, обработку validation/malformed JSON и request ID filter.
2. Настроить JSON logs, trace propagation, Actuator, Prometheus и readiness/liveness.
3. Не включать Entity, бизнес DTO, репозитории или бизнес exceptions в общий модуль.
4. Проверить совместимость starter с MVC и WebFlux.

## Критерии готовности

- [x] MVC и WebFlux тестовые приложения возвращают одинаковый формат ошибок.
- [x] Request ID проходит в ответ и MDC/Reactor Context.
- [x] Starter не тянет JPA/JDBC/R2DBC транзитивно.
