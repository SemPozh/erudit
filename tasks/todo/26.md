# Задача 26. AI-оценка: обратная связь и рекомендации

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-ai-platform
- **Статус:** todo
- **Связанные требования:** REQ 2.9, 2.10

## Описание

AI-оценка должна интерпретировать ответы входного теста, выдавать персональную обратную
связь по сильным и слабым сторонам и рекомендации по направлениям развития.

## Что должно получиться

- Интеграция с AI-провайдером для интерпретации (на старте — заглушка/мок с понятным интерфейсом).
- Генерация обратной связи по тематикам.
- Формирование рекомендаций по направлениям для развития.

## Критерии готовности

- [ ] Обратная связь формируется по результатам теста.
- [ ] Рекомендации по направлениям возвращаются.
- [ ] Интеграция с AI вынесена за интерфейс (заглушка работает).

## Привязка к OpenAPI

Обратная связь включается в ответ GET /api/v1/assessment/me/result из задачи 24; нового маршрута нет.

## Зависимости и проверка

Предшествующие задачи: №23, №24.

Проверить положительный сценарий, ошибки валидации и доступа, а также сохранение/чтение данных там, где это применимо. Для HTTP-маршрутов сверить фактические тела и статусы с OpenAPI и выполнить `./gradlew test openApiValidate build`.
