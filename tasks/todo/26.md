## Описание

AI-оценка должна интерпретировать ответы входного теста, выдавать персональную обратную
связь по сильным и слабым сторонам и рекомендации по направлениям развития.

## Что должно получиться

- Интеграция с AI-провайдером для интерпретации (на старте — заглушка/мок с понятным интерфейсом).
- Генерация обратной связи по тематикам.
- Формирование рекомендаций по направлениям для развития.

## Критерии готовности

- [ ] Обратная связь формируется по результатам теста.
- [ ] Рекомендации по направлениям возвращаются.
- [ ] Интеграция с AI вынесена за интерфейс (заглушка работает).
