# Задача 5. Наблюдаемость: структурированное логирование, метрики, трейсинг

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** инфраструктура
- **Статус:** todo
- **Связанные требования:** NFR 9

## Описание

Настроить базу наблюдаемости монолита: структурированное логирование (JSON),
экспорт метрик (actuator/prometheus), поддержку трейсинга для запросов.

## Что должно получиться

- JSON-логирование с requestId/traceId в контексте запроса.
- Метрики через Spring Boot Actuator (health, метрики).
- Заготовка под трейсинг (корреляционные id в логах).

## Критерии готовности

- [ ] В логах виден структурированный вывод с корреляционным id.
- [ ] `/actuator/health` и базовые метрики доступны.

## Привязка к OpenAPI

Логирование, метрики Actuator и трейсинг; продуктовый маршрут в OpenAPI не требуется.

## Зависимости и проверка

Независимая задача; можно выполнять параллельно с продуктовым API.

Проверить положительный сценарий, ошибки валидации и доступа, а также сохранение/чтение данных там, где это применимо. Для HTTP-маршрутов сверить фактические тела и статусы с OpenAPI и выполнить `./gradlew test openApiValidate build`.
