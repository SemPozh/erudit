# Задача 17. Генерация quiz-карточек из контента

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-content
- **Статус:** todo
- **Связанные требования:** REQ 4.4

## Описание

Из контента любого формата генерировать карточки-вопросы (QuizCard): формулировка факта +
вопрос + правильный ответ, используемые квизами.

## Что должно получиться

- Сущность `QuizCard` и способ генерации из контента (ручной ввод ответа или извлечение).
- `GET /api/v1/content/{id}/quiz-cards` — карточки по контенту.
- Доступ карточек домену квизов.

## Критерии готовности

- [ ] Из статьи/факта формируется корректная quiz-карточка.
- [ ] Карточки доступны домену квизов.
- [ ] Покрыто тестами.
