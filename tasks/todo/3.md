# Задача 3. CI-пайплайн (GitLab CI): сборка, тесты, линт на MR

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** инфраструктура
- **Статус:** todo
- **Связанные требования:** NFR 10

## Описание

Настроить CI для trunk-based разработки: при создании MR и пуше в `main` собирается
проект, прогоняются тесты, при необходимости — линт/статические проверки. Задача —
залог того, что в `main` попадает только рабочий код.

## Что должно получиться

- `.gitlab-ci.yml` (или аналог) со стадиями build и test.
- Сборка через `./gradlew`, прогон тестов, кэширование зависимостей.
- Пайплайн обязан быть зелёным для мержа MR.

## Критерии готовности

- [ ] CI собирает проект и гоняет тесты.
- [ ] Красный пайплайн блокирует мерж.
