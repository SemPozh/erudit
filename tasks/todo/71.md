# Задача 71. Gateway: общий Swagger UI

- **Лабораторная:** ЛР2
- **Исполнитель:** Илья
- **Сервис:** `erudit-gateway`
- **Статус:** todo
- **Оценка изменений:** до 1000 строк, generated-код не считается
- **Зависит от:** 70, 93

## Цель

Собрать единый Swagger UI для внешних API всех микросервисов.

## Что сделать

1. Публиковать список service OpenAPI через Gateway.
2. Сохранить теги по доменам и рабочий `Try it out` на gateway URL.
3. Не показывать внутренние Feign endpoints и схемы авторизации.
4. Добавить проверку уникальности operationId и внешних path.

## Критерии готовности

- [ ] Swagger открывается после `docker compose up --build`.
- [ ] Все девять бизнес-сервисов видны в одном UI.
- [ ] Запросы из UI идут через Gateway и не требуют Authorization.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.

## Проверка

- Unit-тесты для новой логики; integration/Testcontainers для данных и HTTP.
- Запустить проверки изменённых модулей и корневые `./gradlew test openApiValidate build`.
- Проверить запуск изменённых контейнеров и соответствие `docs/lab2-architecture.md`.
