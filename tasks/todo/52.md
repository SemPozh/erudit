# Задача 52. Эмиссия событий доставки/открытия нотификаций

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-notificator
- **Статус:** todo
- **Связанные требования:** REQ 9.7

## Описание

Публиковать события аналитики о нотификациях: получение, открытие, конверсия (переход) —
через внутренний публикатор.

## Что должно получиться

- Публикация `notification_received`, `notification_opened`, `notification_converted`.
- Эндпоинт отметки открытия уведомления из приложения.

## Критерии готовности

- [ ] События доставки/открытия публикуются.
- [ ] Отметка открытия работает.
- [ ] Покрыто тестами.
