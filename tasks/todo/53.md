# Задача 53. Приём и хранение событий аналитики

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-event-reciever
- **Статус:** todo
- **Связанные требования:** REQ 9.1, 9.8, 9.9, 9.10

## Описание

Реализовать API приёма событий аналитики (одиночное и батчем), валидацию, авторизацию,
дедупликацию и запись в ClickHouse.

## Что должно получиться

- `POST /api/v1/events` и `/events/batch` — приём событий.
- Валидация payload и схемы событий.
- Идемпотентность/дедупликация по `eventId`.
- Запись в ClickHouse через клиент (из задачи 4).

## Критерии готовности

- [ ] Одиночные и пакетные события принимаются.
- [ ] Дубли по `eventId` не создаются.
- [ ] Невалидные события отклоняются (400).
