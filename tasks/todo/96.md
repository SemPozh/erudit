## Цель

Проверить основные пользовательские цепочки только через Gateway.

## Что сделать

1. Расширить PowerShell smoke script: registration/profile, category/content, assessment/program/quiz, competition/rating, subscription, notification inbox, events/analytics, admin.
2. Не передавать Authorization; `X-User-Id` использовать только для выбора demo context.
3. Печатать method/path/headers/body/status и завершаться при 401/5xx/contract mismatch.
4. Проверять Circuit Breaker отдельным сценарием остановки AI/payment dependency.

## Критерии готовности

- [ ] Скрипт проходит на свежем `docker compose up --build`.
- [ ] Результат не требует ручного получения ID из БД.
- [ ] Документ содержит PASS/FAIL каждого шага и команды воспроизведения.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
