# Задача 9. Spring Security: JWT-фильтр, защита ресурсов, роли

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.14, 1.15

## Описание

Подключить Spring Security с JWT-фильтром. Настроить, какие ресурсы публичные, какие
защищённые, и ввести роли USER/ADMIN.

## Что должно получиться

- JWT-фильтр, аутентифицирующий запросы по access-токену.
- Матрица прав: публичные (регистрация, вход, каталог, категории) vs защищённые
  (профиль, прогресс, квизы, друзья, подписка, нотификации, аналитика).
- Роли USER и ADMIN с ограничением админ-эндпоинтов.

## Критерии готовности

- [ ] Защищённые эндпоинты требуют токен (401 без него).
- [ ] Админ-эндпоинты доступны только роли ADMIN (403 иначе).
- [ ] Публичные эндпоинты доступны без токена.

## Привязка к OpenAPI

Проверка Bearer-токена и ролей для защищённых маршрутов; собственного HTTP-маршрута нет.
