# Задача 38. Друзья: заявки и список

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 6.4, 6.5, 6.6

## Описание

Реализовать систему друзей: отправка заявки, принятие/отклонение, список друзей, рейтинг
среди друзей (данные для задачи 36).

## Что должно получиться

- Сущность связи «дружба» со статусами (заявка/друзья).
- `POST /api/v1/friends/requests` (отправка), принять/отклонить, список друзей.
- Учёт приватности.

## Критерии готовности

- [ ] Заявка отправляется и принимается/отклоняется.
- [ ] Список друзей корректен.
- [ ] Покрыто тестами.
