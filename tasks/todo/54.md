# Задача 54. Справочник типов событий

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-event-reciever
- **Статус:** todo
- **Связанные требования:** REQ 9.2, 9.3, 9.4, 9.5, 9.6, 9.7

## Описание

Описать справочник типов событий по группам: навигация/клики, контент, квизы, социальное,
монетизация, нотификации. Использовать для валидации и аналитики.

## Что должно получиться

- Перечисление/таблица типов событий по группам.
- Валидация eventType при приёме.
- Использование справочника в дашбордах.

## Критерии готовности

- [ ] Все требуемые группы типов событий описаны.
- [ ] Неизвестный eventType отклоняется.
- [ ] Справочник используется в аналитике.

## Привязка к OpenAPI

Схема и миграции аналитических событий в ClickHouse; HTTP-маршрут отправки относится к задаче 53.

## Зависимости и проверка

Предшествующие задачи: №4.

Проверить положительный сценарий, ошибки валидации и доступа, а также сохранение/чтение данных там, где это применимо. Для HTTP-маршрутов сверить фактические тела и статусы с OpenAPI и выполнить `./gradlew test openApiValidate build`.
