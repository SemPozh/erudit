- **Лабораторная:** ЛР2
- **Исполнитель:** Семен

- **Статус:** todo

- **Зависит от:** 67, 68, 69, 72

## Цель

Закрыть дефект ЛР1: дать полноценный API категорий и данные, пригодные для Swagger.

## Что сделать

1. Перенести таблицу categories и seed с постоянными UUID.
2. Добавить `POST /api/v1/content/categories`, `PUT` и `DELETE /{id}` плюс существующий paged GET.
3. Запретить удаление используемой категории понятным 409.
4. Добавить OpenAPI examples и validation имени; без ролей и авторизации.

## Критерии готовности

- [ ] Категорию можно создать, изменить, получить и удалить через Swagger.
- [ ] Создание контента возможно с ID из GET без SQL.
- [ ] PostgreSQL Testcontainers проверяет unique name, FK conflict и пагинацию.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
