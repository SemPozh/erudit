# Задача 33. Ежедневный квиз

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-quiz
- **Статус:** todo
- **Связанные требования:** REQ 5.7

## Описание

Реализовать ежедневный квиз: генерация, одна попытка в день, сохранение результата.

## Что должно получиться

- Генерация ежедневного квиза (по прогрессу/тематикам).
- Ограничение одной попытки в день.
- Результат сохраняется и доступен.

## Критерии готовности

- [ ] Ежедневный квиз доступен раз в день.
- [ ] Повторная попытка в тот же день отклоняется.
- [ ] Результат сохраняется.
