# Задача 12. Настройки профиля

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 1.8, 1.9, 1.10, 3.5

## Описание

Реализовать настройки профиля: интерфейс/локализация (язык, часовой пояс), обучение
(любимые тематики, ежедневная цель), приватность (видимость в поиске/рейтинге, согласие
на аналитику). Это источник предпочтений для подбора программы и нотификаций.

## Что должно получиться

- Сущность настроек пользователя и миграция.
- API чтения/обновления настроек.
- Любимые тематики и ежедневная цель доступны другим доменам (программа, нотификации).

## Критерии готовности

- [ ] Настройки читаются и обновляются.
- [ ] Изменения сразу вступают в силу.
- [ ] Настройки согласия на аналитику учитываются.
