- **Зависит от:** 67, 93, 95

## Цель

Перестроить pipeline для независимых сервисов и полного системного gate.

## Что сделать

1. Добавить validate OpenAPI, unit/integration tests, coverage и build всех модулей.
2. Собирать Docker image каждого приложения и проверять Dockerfiles.
3. Использовать Gradle cache и path filtering без пропуска обязательного root check.
4. Добавить Compose config validation и smoke инфраструктуры.

## Критерии готовности

- [ ] PR не мержится при падении любого сервиса или контракта.
- [x] Все образы имеют immutable build metadata и non-root runtime.
- [x] Pipeline не содержит реальных секретов/внешних provider calls.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
