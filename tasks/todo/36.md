# Задача 36. Рейтинг: общий, по тематикам, за периоды, позиция

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-user
- **Статус:** todo
- **Связанные требования:** REQ 6.1, 6.2, 6.7

## Описание

Реализовать рейтинг пользователей: общий по очкам, по тематикам, за периоды (день/неделя/
месяц), а также позицию/ранг пользователя и рейтинг среди друзей.

## Что должно получиться

- `GET /api/v1/rating` — рейтинг с фильтрами (тематика, период) и пагинацией.
- `GET /api/v1/rating/me` — позиция/ранг пользователя.
- `GET /api/v1/rating/friends` — рейтинг среди друзей.
- Учёт приватности (видимость в рейтинге).

## Критерии готовности

- [ ] Рейтинг по очкам, тематикам и периодам корректен.
- [ ] Позиция пользователя и среди друзей отображается.
- [ ] Приватность учитывается.
