# Задача 4. ClickHouse в docker-compose + клиент + базовая схема событий

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-event-reciever
- **Статус:** todo
- **Связанные требования:** REQ 9.9, 9.10

## Описание

Подключить ClickHouse в `docker-compose`, добавить клиент для записи, создать базовую
схему таблицы событий аналитики (MergeTree, партиционирование по дате).

## Что должно получиться

- ClickHouse-сервис в `docker-compose.yml`.
- Клиентская зависимость и конфигурация подключения.
- Миграция/скрипт создания таблицы событий с ключевыми полями (userId, sessionId,
  eventType, timestamp, payload, eventId) и индексами.

## Критерии готовности

- [ ] ClickHouse поднимается в compose.
- [ ] Схема таблицы событий создаётся.
- [ ] Есть smoke-тест записи/чтения события.
