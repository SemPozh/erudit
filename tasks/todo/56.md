# Задача 56. Дашборды аналитики

- **Исполнитель:** Семен
- **Домен (будущий микросервис):** erudit-event-reciever
- **Статус:** todo
- **Связанные требования:** REQ 9.11, 9.12, 9.13, 9.14, 9.15, 9.16

## Описание

Реализовать эндпоинты дашбордов на основе ClickHouse: DAU/WAU/MAU, сессии, вовлечённость
(просмотры, дочитывания, время на формат), обучение (квизы, % верных, темп), воронки,
монетизация (конверсия в премиум), эффективность нотификаций (CTR, возврат, отписки).

## Что должно получиться

- `GET /api/v1/analytics/*` для каждой метрики (с периодом и granularity).
- SQL-агрегаты к ClickHouse.
- Согласованные структуры ответов для дашбордов.

## Критерии готовности

- [ ] Метрики по всем группам доступны.
- [ ] Агрегаты корректны и параметризуются периодом.
- [ ] Покрыто тестами.
