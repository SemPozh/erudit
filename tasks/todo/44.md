# Задача 44. История платежей и безопасное хранение

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-payment
- **Статус:** todo
- **Связанные требования:** REQ 7.8, 7.9, NFR 6, 7

## Описание

Хранить историю платежей пользователя, не храня платёжные данные в открытом виде.

## Что должно получиться

- Сущность платежа (пользователь, сумма, статус, дата, внешний id) — без платёжных реквизитов.
- `GET /api/v1/subscriptions/payments` — история платежей.
- Гарантия отсутствия открытых платёжных данных.

## Критерии готовности

- [ ] История платежей читается пользователем.
- [ ] Платёжные реквизиты не хранятся.
- [ ] Покрыто тестами.
