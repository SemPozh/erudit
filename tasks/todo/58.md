# Задача 58. Аудит действий администрирования

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-admin
- **Статус:** todo
- **Связанные требования:** NFR 8

## Описание

Логировать действия администрирования (модерация контента, массовые уведомления, блокировка
пользователей) для аудита.

## Что должно получиться

- Сущность/таблица аудит-лога (кто, что, когда, кого затронуло).
- Запись действий при админ-операциях.
- `GET /api/v1/admin/audit` только для ADMIN: пагинация `page`/`size`,
  фильтры `actorId`, `action`, `from`, `to`, порядок от новых записей к старым.
- В записи хранить идентификатор действия, дату, администратора, тип и ID цели,
  результат; не сохранять секреты и тела платёжных запросов.

## Критерии готовности

- [ ] Админ-действия логируются.
- [ ] Лог содержит достаточный контекст.
- [ ] Обычный пользователь получает 403; фильтры и страницы возвращают
      стабильный результат, повторный запрос не меняет историю.
- [ ] Покрыто тестами.
