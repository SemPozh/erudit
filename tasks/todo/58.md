# Задача 58. Аудит действий администрирования

- **Исполнитель:** Дестини
- **Домен (будущий микросервис):** erudit-admin
- **Статус:** todo
- **Связанные требования:** NFR 8

## Описание

Логировать действия администрирования (модерация контента, массовые уведомления, блокировка
пользователей) для аудита.

## Что должно получиться

- Сущность/таблица аудит-лога (кто, что, когда, кого затронуло).
- Запись действий при админ-операциях.
- Доступ к логу для аудита.

## Критерии готовности

- [ ] Админ-действия логируются.
- [ ] Лог содержит достаточный контекст.
- [ ] Покрыто тестами.
