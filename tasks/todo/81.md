# Задача 81. Quiz service: соревнования и рейтинг

- **Лабораторная:** ЛР2
- **Исполнитель:** Дестини
- **Сервис:** `erudit-quiz`
- **Статус:** todo
- **Оценка изменений:** до 1850 строк, generated-код не считается
- **Зависит от:** 75, 80, 91

## Цель

Перенести competition и rating без прямого доступа к user/content данным.

## Что сделать

1. Перенести создание, участников, приглашения, leaderboard и рейтинги.
2. Проверку пользователя/друга выполнять через User Feign; сбой обрабатывать Circuit Breaker.
3. Уведомление о приглашении ставить в mock notificator через Feign.
4. Добавить demo competition и стабильные ID для Swagger.

## Критерии готовности

- [ ] Competition/rating paths работают через Gateway.
- [ ] Нет FK в user database и нет реальной отправки уведомлений.
- [ ] Тесты покрывают участника, повтор приглашения, период рейтинга и недоступные зависимости.

## Общие ограничения ЛР2

- Авторизацию, JWT, Spring Security и проверки ролей не добавлять.
- Реальные email, push и SMS не отправлять; это относится к ЛР4.
- Не обращаться напрямую к БД другого сервиса и не переиспользовать его Entity.
- Внешние HTTP DTO задаются OpenAPI; generated-код не коммитится.
- Если фактический diff достигает 1800 строк, остаток вынести в новую задачу до PR.
