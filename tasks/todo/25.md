# Задача 25. Система грейдов (лиги/титулы)

- **Исполнитель:** Илья
- **Домен (будущий микросервис):** erudit-ai-platform
- **Статус:** todo
- **Связанные требования:** REQ 2.5, 2.6

## Описание

На основе ER-score присваивать грейд/титул из лиг с подуровнями (Новичок → Знаток →
Эрудит → Магистр → Легенда). Грейд динамически пересчитывается по мере обучения.

## Что должно получиться

- Таблица лиг/порогов грейдов и подуровней.
- Расчёт текущего грейда по ER-score.
- Пересчёт грейда при изменении ER-score (за квизы, контент, streak).
- Отображение грейда в профиле.

## Критерии готовности

- [ ] Грейд корректно определяется по рейтингу.
- [ ] Пересчёт при изменении ER-score работает.
- [ ] Покрыто тестами.

## Привязка к OpenAPI

Правила выбора сложности используются программой обучения; отдельного HTTP-маршрута нет.
